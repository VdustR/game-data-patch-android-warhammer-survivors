# Search and AI discovery

The English editor ships its useful content in the initial HTML. The browser hydrates that same Svelte component for local save editing. Search crawlers and people receive the same page; there is no crawler-specific rendering, hidden answer text, upload endpoint, or tracking.

## Applied changes

- **English throughout:** page language, title, description, controls, accessible names, validation messages, Node output, and the JavaScript-disabled notice.
- **Static content:** the editor, device-tested build, file recognition rules, changed fields, privacy, offline downloads, installation guidance, and cloud-persistence limits are readable without JavaScript. Editing still requires JavaScript and Web Crypto; file selection stays disabled until the app starts.
- **One canonical URL:** the HTTPS GitHub Pages project URL appears in the canonical link, social metadata, WebApplication JSON-LD, and [sitemap](https://vdustr.github.io/game-data-patch-android-warhammer-survivors/sitemap.xml). The offline copy identifies the public page as canonical. There are no language variants requiring `hreflang`.
- **Factual structured data:** the application name, purpose, English language, free access, browser requirements, image, and public creator identity match visible content. There are no invented ratings or reviews and no claim of eligibility for a particular rich result.
- **Useful attribution:** the guide links to the source repository, usage instructions, release downloads, and device verification record. Test dates describe actual observations, not artificial freshness.

## Verification and limits

`pnpm verify` checks the initial response and the actual JavaScript-disabled page, canonical URL, JSON-LD, sitemap, client hydration, online/offline patch downloads, validation recovery, and responsive layouts. The downloaded standalone HTML must work with the network disabled and produce the same bytes as the shared patching core. Build artifacts contain no private saves.

A crawlable page does not prove indexing, ranking, AI citation, or increased traffic. Those outcomes require later observation in the relevant search service. Search Console or Bing Webmaster Tools ownership and sitemap submission are optional account-level follow-up, not performed by this build. A sitemap under the project path is available for submission; no host-root discovery claim is made.

Device compatibility remains limited to the [recorded evidence](../VERIFICATION.md). Search improvements do not establish compatibility with another game version or prove restart/cloud persistence.
